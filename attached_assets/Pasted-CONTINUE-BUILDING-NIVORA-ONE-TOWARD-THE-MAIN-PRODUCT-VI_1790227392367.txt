MAIN PRODUCT VISION:

NIVORA ONE should become an AI-powered professional work and problem-solving platform.

The AI should not be only a question-answer chatbot.

Users should be able to bring a problem, file, code, business question, content requirement, or website/app problem to NIVORA AI and receive practical help and, where technically safe and possible, generated solutions.

BUILD THIS AS THE NEXT CAPABILITY:

NEW AI MODE:
"Problem Solver"

The existing AI mode selector should become:

- General AI
- Business AI
- Content Creator
- Coding Assistant
- Problem Solver
- App / Website Builder

PROBLEM SOLVER SHOULD SUPPORT:

1. Code problems
User can provide:
- HTML
- CSS
- JavaScript
- Python
- JSON
- Node.js
- Firebase code
- API code
- error messages

The AI should:
- understand the problem
- identify likely causes
- explain the problem simply
- provide corrected code
- identify which file should be changed
- provide exact replacement instructions when possible
- avoid inventing missing code

2. Website problems

Examples:
"My login button doesn't work."
"My page has a white overlay."
"My mobile layout is broken."
"My JavaScript button does nothing."

The AI should analyze supplied code/files and produce a practical fix.

3. App problems

When project files are supplied, the AI should be able to:
- inspect relevant files
- identify related code
- explain the problem
- propose changes
- generate corrected files/code
- provide a clear test checklist

IMPORTANT:
Do not execute arbitrary user-generated code on the server.

4. File-based problem solving

Prepare the architecture for users to upload supported files such as:
- HTML
- CSS
- JS
- JSON
- TXT
- CSV
- MD
- PDF
- images where appropriate

Use Firebase Storage where appropriate.

Do not expose private files to other users.

5. Business problem solving

The existing Business AI should eventually answer questions using verified user data.

For this stage, do not claim browser data is authoritative.

6. CONTENT PROBLEM SOLVING

Allow users to ask things such as:

"এই Facebook পোস্টটা ভালো করে দাও।"

"এই বিজ্ঞাপনটা আরও professional করো।"

"আমার product description তৈরি করো।"

"এই YouTube script ঠিক করো।"

7. APP / WEBSITE BUILDER

Keep Builder mode.

It should currently:
- understand requirements
- generate HTML/CSS/JS
- generate project structure
- modify supplied code conceptually
- explain changes

Do NOT execute arbitrary generated code.
